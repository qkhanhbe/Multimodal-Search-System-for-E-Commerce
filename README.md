# Multimodal Search System for E-Commerce

Assignment 06: a three-layer Python prototype for e-commerce product and order search using text, simulated voice, images, or text + image.

## Run the demo

```powershell
cd assignment06
python -m pip install numpy pillow
python main.py
```

See [assignment06/README.md](assignment06/README.md) for individual search commands, evaluation, and implementation details.

## Project files

- `assignment06/` - Python source, sample products, and query images
- `diagrams/` - UML diagrams
- `demo_results/` - sample output and evaluation results
- `Assignment06_KHANHBQ.vpp` - Visual Paradigm project
- `A6_v1_04_049_KHANHBQ.pdf` - assignment report
- `inf_sys_analysis_design_assignment_06_design_code.pdf` - assignment brief
